# PalindromeCheckerApp
This is a simple Java console application that checks whether a given word is a palindrome.

A palindrome is a word that reads the same forward and backward (e.g., madam, racecar, level).

The program:

Accepts user input

Reverses the input string

Compares the original and reversed strings (case-insensitive)

Displays whether it is a palindrome or not
